## Trust Boundaries
| Boundary | Description |
|---|---|
| Controller to guard host | Controller failure must not remove teardown authority. |
| Guard to provider | Guard has privileged destroy ability and must not act on unowned resources. |
| Guard secret file | Provider credential is sensitive and remains external to this repository. |
