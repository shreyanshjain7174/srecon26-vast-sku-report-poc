<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Runner to local Kubernetes cluster | A mistaken context or shared cluster must not be changed by this harness. |
| Metrics inputs to evidence bundle | Synthetic data could otherwise overstate independence or be mislabeled as real GPU evidence. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-01-11 | Tampering | local_hpa.py | mitigate | Evaluate every time-series sample, declared maximum, target margin, non-target margin, and transition window. |
| T-01-12 | Spoofing | run_local_arm.py | mitigate | Require explicit ownership label before cluster mutation and reject unowned contexts/resources. |
| T-01-13 | Repudiation | collect_local_evidence.py | mitigate | Capture timestamped raw samples, HPA events, replica timeline, and provenance in each bundle. |
| T-01-14 | Information disclosure | k8s/local | accept | Local manifests carry no secrets and use no provider credential. |
| T-01-SC | Tampering | Kubernetes tooling | accept | No dependency is installed; manifest application is dry-run or owned local-only. |
</threat_model>
