<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Local artifacts to integrity bundle | Run artifacts could be missing, altered, mislabeled, or from an incorrect time window. |
| Controller to guard journal | Local evidence has no external anchor until the independent guard acknowledges its root hash. |
| Developer commit to repository hook | Source and staged content can introduce secrets or high-severity findings unless checked before commit. |
| Preflight gate to provider state | A safety check must not itself create cost exposure or mutate a provider resource. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-01-15 | Tampering | integrity.py | mitigate | Explicit manifest, SHA-256 checksums, root hash, timestamp/order/provenance validation, and guard receipt verification. |
| T-01-16 | Repudiation | anchor_local_evidence.py | mitigate | Persist the guard acknowledgment and require it before preparing the signed evidence commit. |
| T-01-17 | Information disclosure | .githooks/pre-commit | mitigate | Block credential patterns before commit and retain explicit secret-free source tests. |
| T-01-18 | Elevation | prepaid_gate.py | mitigate | Make preflight read-only; prohibit create, destroy, and report-submit operations and test that contract. |
| T-01-19 | Tampering | .semgrep.yml | mitigate | Semgrep failures block commit hooks and paid-run gate output; high-severity findings cannot be waived silently. |
| T-01-SC | Tampering | Semgrep executable | accept | No package is installed by the plan; if Semgrep is absent, setup and the paid-run gate fail closed. |
</threat_model>
