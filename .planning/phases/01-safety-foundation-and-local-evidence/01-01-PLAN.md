  <behavior>
    - An invalid skipped state transition raises a typed error and does not append an event.
    - A persisted event has a monotone sequence, prior-event hash, canonical payload hash, UTC wall time, and monotonic timestamp.
    - Reopening validates run identity, sequence, state transition, monotonic ordering, and the complete hash chain.
    - A final unterminated or unparsable partial line is truncated only when it is the final tail; corruption of any earlier record fails closed.
    - A journal containing `provider.create_intent` retains that intent after reopen, so later controller code can resume without issuing a second create.
    - A terminal halt stores exception class, safe message, and traceback hash in a structured `HALT` event.
  </behavior>
